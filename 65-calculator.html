How this is calculated

Break-even = (fixed cost per occupied night + cleaning ÷ avg stay + other variable cost) ÷ (1 − fees%) — occupied nights per month = 30.4 × expected occupancy.

Hard floor = break-even ÷ 0.90 (10% occupancy-safety buffer) · Last-minute floor = hard floor × 0.85, never below marginal cost · Orphan gap fill = marginal cost × 1.10 — any rate above true variable cost beats an empty night · Weekend floor = hard floor × 1.15 · Low-season base = hard floor × 1.05 · Peak minimum = hard floor × 1.50.
